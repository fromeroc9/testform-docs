---
title: "Stacks y Suites de Ejecución"
---

En Terraform, un *Stack* o *Configuration Module* agrupa recursos para ser desplegados en conjunto. En Testform, esta capacidad se implementa a través de los scopes **`testrun`** (ciclos de ejecución) y **`testplan`** (planes maestros), gestionados mediante el comando `testform suite`.

---

## Generación de Suites por Etiquetas (`bracket tags`)

Testform permite extraer escenarios que compartan una etiqueta y empaquetarlos en un archivo de suite `.run.feature`:

```bash
# Extrae todos los escenarios marcados con @smoke en el workspace
testform suite tags "[@smoke]" -title="Regresión Rápida de Smoke"

# Extrae solo escenarios @critical de un feature específico
testform suite tags "checkout.case.feature.[@critical]" -title="Checkout Crítico"
```

El resultado es un archivo declarativo `.run.feature`:

```gherkin
@testrun @tr-01
Feature: Regresión Rápida de Smoke

  Rule: auth.case.feature
    Scenario: Login exitoso con credenciales válidas
      * mark status = pending

  Rule: checkout.case.feature
    Scenario: Pago con tarjeta de crédito
      * mark status = pending
```

---

## Estrategias de Dirección (`-target`)

Al interactuar con suites, puedes referenciar el recurso mediante 3 estrategias:

1. **Tag de Identidad (@tr-N / @tp-N):**
   ```bash
   testform suite -target="@tr-01" -fill
   ```
2. **Dirección Canónica:**
   ```bash
   testform suite -target="specs/runs/smoke.run.feature.@tr-01" -fill
   ```
3. **Ruta Relativa:**
   ```bash
   testform suite -target="smoke.run.feature" -fill
   ```

---

## Registro de Estado de Ejecución (`mark`)

Una vez ejecutada la prueba en tu runner (Playwright, Cypress, Supertest o K6), actualizas el estado en el archivo y sincronizas con GitHub:

```bash
testform suite -target="@tr-01" -mark="@tc-01=passed"
```

El motor actualiza la línea en el feature:
```gherkin
Scenario: Login exitoso con credenciales válidas
  * mark status = passed
```
Y al ejecutar `testform apply`, la tarjeta en **GitHub Projects V2** se mueve automáticamente a la columna **Done**.
