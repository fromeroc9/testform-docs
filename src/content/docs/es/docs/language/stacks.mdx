---
title: "Stacks y Suites de Ejecución"
---

En Terraform, un *Stack* o *Configuration Module* agrupa recursos para ser desplegados en conjunto. En Testform, esta capacidad se implementa a través de los scopes **`testrun`** (ciclos de ejecución) y **`testplan`** (planes maestros), gestionados mediante el comando `testform spec`.

---

## Generación de Suites por Etiquetas (`--include`)

Testform permite extraer escenarios que compartan una etiqueta o archivo y empaquetarlos en un archivo de suite `.run.feature`:

```bash
# Extrae todos los escenarios marcados con @smoke en el workspace
testform spec testrun new --include="smoke" --title="Regresión Rápida de Smoke"

# Extrae escenarios críticos de un feature específico
testform spec testrun new --include="checkout.case.feature" --title="Checkout Crítico"
```

El resultado es un archivo declarativo `.run.feature`:

```gherkin
@testrun @tr-01
Feature: Regresión Rápida de Smoke

  Rule: auth.case.feature
    Scenario: @tc-01
      * set status = pending

  Rule: checkout.case.feature
    Scenario: @tc-01
      * set status = pending
```

---

## Estrategias de Dirección (`--target`)

Al interactuar con suites, puedes referenciar el recurso mediante 3 estrategias:

1. **Tag de Identidad (@tr-N / @tp-N):**
   ```bash
   testform spec testrun fill --target="@tr-01"
   ```
2. **Dirección Canónica:**
   ```bash
   testform spec testrun fill --target="testruns/smoke.run.feature.@tr-01"
   ```
3. **Ruta Relativa:**
   ```bash
   testform spec testrun fill --target="smoke.run.feature"
   ```

---

## Registro de Estado de Ejecución (`set`)

Una vez ejecutada la prueba en tu runner (Playwright, Cypress, Supertest o K6), actualizas el estado en el archivo y sincronizas con GitHub:

```bash
testform spec testrun set --target="@tr-01" --case="auth.case.feature.@tc-01" --status=passed
```

El motor actualiza la línea en el feature:
```gherkin
Scenario: @tc-01
  * set status = passed
```
Y al ejecutar `testform apply`, la tarjeta en **GitHub Projects V2** se mueve automáticamente a la columna **Done**.
