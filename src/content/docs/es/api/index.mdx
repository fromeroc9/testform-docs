El paquete `@fromeroc9/testform@beta` expone una **API programática de TypeScript / JavaScript** diseñada para desarrolladores, ingenieros de plataforma QA y creadores de extensiones.

Permite registrar políticas de calidad personalizadas, plantillas de recursos de pruebas, backends de almacenamiento distribuido, adaptadores de proveedores y evaluar expresiones de configuración de forma programática.

---

## 📦 Instalación del SDK

Para interactuar con la API de Testform en tus scripts de automatización o paquetes de plugins:

```bash
npm install @fromeroc9/testform@beta --save-dev
```

O si usas Yarn / pnpm:

```bash
pnpm add -D @fromeroc9/testform@beta
```

## 🏛️ Módulos de la API

La API de Testform está dividida en los siguientes bloques funcionales:

### 1. [Políticas (`registerPolicy`)](/es/api/policies)
Extiende el analizador estático para validar convenciones de nomenclatura, tags obligatorios, estructura de escenarios Gherkin o integración con tickets corporativos antes de generar planes.

### 2. [Recursos (`registerResource`)](/es/api/resources)
Registra mapeadores personalizados para traducir escenarios Gherkin a entidades externas (Jira, Zephyr, Azure DevOps, TestRail o servicios propietarios).

### 3. [Backends (`IBackend`)](/es/api/backends)
Implementa conectores de almacenamiento de estado personalizados (`backend.custom`) para guardar el archivo `testform.state` y controlar bloqueos concurrentes en cualquier sistema distribuido (Vault, Redis, Firestore, etc.).

### 4. [Proveedores (`IProvider`)](/es/api/providers)
Implementa conectores para sincronizar el ciclo de vida de casos de prueba, corridas y planes contra APIs de gestión de proyectos.

### 5. [Evaluador de Expresiones (`evaluateExpression`)](/es/api/expressions)
Evalúa expresiones tipo HCL `${...}`, llamadas a funciones estándar y lógica condicional programáticamente en Node.js.

### 6. [Gestor de Estado (`State`)](/es/api/state)
Lee, inspecciona, bloquea y actualiza el archivo `testform.state` con control de linaje (*lineage*) y números de serie.

### 7. [Funciones Integradas](/es/functions)
Catálogo completo de funciones matemáticas, cadenas, colecciones y utilidades del sistema (`uuid()`, `trim()`, `jsonencode()`, etc.).
