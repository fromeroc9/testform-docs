---
title: "testform modules"
description: "Muestra todos los módulos declarados en el espacio de trabajo actual."
---

```bash
testform [opciones globales] modules [opciones]
```

El comando `testform modules` inspecciona la configuración actual (`main.yml` y archivos de dominio) y muestra la lista o árbol de todos los módulos declarados en el espacio de trabajo, junto con sus fuentes (`source`), versiones resueltas y directorios asociados.

Sigue la misma filosofía y formato que `terraform modules`, permitiendo auditar la procedencia de los módulos de prueba reutilizables tanto locales como remotos (Git).

---

## Opciones del Comando

| Opción | Por Defecto | Descripción |
| :--- | :--- | :--- |
| `-json` | `false` | Emite la lista de módulos declarados y sus versiones resueltas en formato legible por máquina. |
| `-var 'foo=bar'` | — | Define un valor para una variable de entrada en el módulo raíz. Puede usarse varias veces. |
| `-var-file=filename` | — | Carga valores de variables desde el archivo indicado, además de los archivos por defecto `testform.vars.yml` y `*.auto.vars.yml`. |

---

## Ejemplos de Uso

### 1. Sin módulos declarados

```bash
$ testform modules
No modules found in configuration.
```

Y en formato JSON:

```bash
$ testform modules -json
{"format_version":"1.0","modules":null}
```

### 2. Vista en árbol (con módulos declarados)

```bash
$ testform modules

Modules declared in configuration:
.
├── module.auth_standard
│   source: ./modules/auth/login.case.feature
│   scenario: @tc-login
│   vars: user="admin", timeout=5000
└── module.auth_shared
    source: git::https://github.com/mi-org/qa-modules.git//auth?ref=v1.2.0
    version: v1.2.0
    dir: .testform/modules/auth_shared
```

### 3. Salida en formato JSON (`-json`)

Ideal para scripts de automatización, linters o inspección en pipelines de CI/CD:

```bash
$ testform modules -json
{
  "format_version": "1.0",
  "modules": [
    {
      "Key": "",
      "Source": "",
      "Dir": "."
    },
    {
      "Key": "auth_standard",
      "Source": "./modules/auth/login.case.feature",
      "Dir": "modules/auth"
    },
    {
      "Key": "auth_shared",
      "Source": "git::https://github.com/mi-org/qa-modules.git//auth?ref=v1.2.0",
      "Version": "v1.2.0",
      "Dir": ".testform/modules/auth_shared"
    }
  ]
}
```

---

## Códigos de Salida

- `0`: Comando ejecutado exitosamente.
- `1`: Error de lectura o archivo de configuración malformado.
