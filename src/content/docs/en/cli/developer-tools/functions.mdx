---
title: "testform functions"
description: "Inspect, explore, and evaluate built-in expression functions interactively."
---

```bash
testform functions [name] [options]
```

The `testform functions` command allows you to inspect, explore, and interactively evaluate the built-in function library of Testform's expression engine. These functions are used both in `locals.yml` for dynamic computations and in validation conditions within `variables.yml`.

---

## 2. Detailed Function Documentation
To inspect the complete signature, argument types, and usage examples for a specific function:

```bash
testform functions format
```

Terminal output:
```text
Testform Expression Function: format
  Category:    String & Text
  Signature:   format(format, ...args) -> string
  Description: Formats a string using verbs (%s for string, %d for integer, %j for JSON, %% for literal %).

Arguments:
  - format [string]: Format string containing placeholders.
  - args [any...]: Values to interpolate.

Examples:
  $ format("%s/%s", var.base_url, "api/v1")
    => "https://example.com/api/v1"
  $ format("run-%03d", 5)
    => "run-5"
```

Another example:
```bash
testform functions contains
```

## 3. Live Evaluation with `--eval`
You can test any mathematical expression, logical condition, or function call in real time directly from your terminal to verify the resulting value and type:

```bash
testform functions --eval "format('%s/%s', 'https://api.example.com', 'v1')"
```

Output:
```text
Expression Evaluation:
  Input:  format('%s/%s', 'https://api.example.com', 'v1')
  Type:   string
  Result: "https://api.example.com/v1"
```

Evaluating collections and logic:
```bash
testform functions --eval "contains(['dev', 'staging', 'prod'], 'qa')"
```

Output:
```text
Expression Evaluation:
  Input:  contains(['dev', 'staging', 'prod'], 'qa')
  Type:   boolean
  Result: false
```

---

## Options

| Option | Description |
| :--- | :--- |
| `[name]` | Name of the built-in function to inspect (`lower`, `upper`, `format`, `contains`, etc.). |
| `--eval "<expr>"` | Evaluates a test expression in real time and prints the resulting type and value. |

---

## Exit Codes

- `0`: Command executed successfully.
- `1`: Malformed expression or syntax error encountered during AST parsing.
