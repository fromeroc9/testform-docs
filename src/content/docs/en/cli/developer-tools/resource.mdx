---
title: "testform resource"
---

```bash
testform [global options] resource [action] [name] [options]
```

The `testform resource` command inspects, lists, and scaffolds templates for **custom resources** (`ResourceTemplate`), stored under `.testform/resources/`, `./resources/`, or loaded via shared modules.

:::note[Decoupled Resource Architecture]
Resources define the contract between Gherkin scenarios (`Scenario:`) and providers (`IProvider`). Through a resource template, you specify canonical `attributes`, persisted `state` fields, and optional `lifecycle` hooks.
:::

---

## List Registered Resources (`testform resource` or `testform resource list`)

Run the command without subcommands or with `list` to inspect all registered resources in the workspace:

```bash
$ testform resource

REGISTERED RESOURCE TEMPLATES
────────────────────────────────────────
  • github_testcase
  • github_testrun
  • github_testplan
  • register-pokemon             [lifecycle hooks]

Use 'testform resource scaffold <name>' to generate a new template.
```

---

## Scaffold a New Resource (`scaffold` / `new`)

To quickly bootstrap a type-safe custom resource template with attributes, state, and lifecycle hooks:

```bash
$ testform resource scaffold pokemon_trainer

✔ Successfully scaffolded custom resource template at:
  /path/to/project/.testform/resources/pokemon_trainer.ts

Resource type: pokemon_trainer
Edit the file to customize attributes, state fields, and lifecycle hooks.
```

The generated file contains a ready-to-use template:

```typescript
import { ResourceTemplate, ParserScenario } from '@fromeroc9/testform';

export const pokemon_trainerResource: ResourceTemplate = {
    // Unique resource type identifier
    type: "pokemon_trainer",

    // Canonical attributes evaluated from the Gherkin scenario
    attributes: (scenario: ParserScenario, context?: any) => ({
        title: scenario.name,
        description: scenario.description,
        tags: scenario.tags,
        ...scenario.custom?.fields
    }),

    // Attributes stored in state (.testform/state.json)
    state: {
        status: (scenario: ParserScenario) => scenario.custom?.fields?.status || 'active',
        synced_at: () => new Date().toISOString()
    },

    // Lifecycle hooks
    lifecycle: {
        beforeCreate: async ({ attributes, scenario, context }) => {},
        afterCreate: async ({ id, attributes, provider, scenario, context }) => {},
        beforeUpdate: async ({ id, attributes, provider, scenario, context }) => {},
        afterUpdate: async ({ id, attributes, diff, provider, scenario, context }) => {},
        beforeDelete: async ({ id, provider, context }) => {},
        afterDelete: async ({ id, provider, context }) => {}
    }
};

export default pokemon_trainerResource;
```

## Inspect a Resource (`show`)

Display details and lifecycle hooks for a specific resource type:

```bash
$ testform resource show register-pokemon

Resource Template: register-pokemon
  Type:        register-pokemon
  Attributes:  function(scenario, context)
  State:       region, capturadoEn
  Lifecycle:   beforeCreate, afterCreate
```

---

## Options

| Option | Description |
| :--- | :--- |
| `scaffold <name>` | Generate a new template in `.testform/resources/<name>.ts`. |
| `show <name>` | Show details and hooks for a specific resource. |
| `list` | List all registered resources (default action). |
| `--json` | Output response in structured JSON. |
| `-C, --chdir <dir>` | Switch working directory before executing command. |
