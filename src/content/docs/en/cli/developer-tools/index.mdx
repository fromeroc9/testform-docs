Operational utilities for developers and QA engineers to optimize formatting, validation, inspection, AST parsing, and reporting of test infrastructure.

## Available Commands

- **[`testform suite`](./suite):** Manages test suites and execution files (`init`, `-fill`, `-link`, `-mark`, `-tags`).
- **[`testform validate`](./validate):** Statically validates `.feature` file syntax and governance policies.
- **[`testform fmt`](./fmt):** Reformats Gherkin feature files and YAML configurations to canonical style.
- **[`testform diff`](./diff):** Displays line-by-line differences between local specifications and state.
- **[`testform show`](./show):** Inspects execution plans or state snapshots in human-readable or JSON format.
- **[`testform query`](./query):** Performs advanced queries across repository resources using tag expressions.
- **[`testform policy`](./policy):** Inspects, enables, and disables quality governance policies at runtime.
- **[`testform modules`](./modules):** Shows all declared modules and their resolved versions in the working directory.
- **[`testform providers`](./providers):** Displays the provider requirements tree and resource schemas for the configuration.
- **[`testform functions`](./functions):** Inspects and evaluates built-in expression functions interactively.
- **[`testform print`](./print):** Parses a `.feature` file and prints its JSON Abstract Syntax Tree (AST).
- **[`testform graph`](./graph):** Generates a visual Directed Acyclic Graph (DAG) in DOT, Mermaid, or tree format.
- **[`testform report`](./report):** Generates multi-dimensional analytical reports in Markdown, Word (.docx), Excel (.xlsx), JSON, and CSV.
