Commands for inspecting, directly modifying, importing, and clearing locks on the state ledger.

## State and Storage Commands

- **[`testform state`](./state):** Directly inspects and modifies entries in the state ledger (`list`, `show`, `rm`, `pull`, `push`, `mv`, `replace-provider`, `clean`).
- **[`testform output`](./output):** Reads and emits output variables saved in the active state file.
- **[`testform import`](./import):** Imports existing test entities from remote issue trackers into the state ledger.
- **[`testform taint`](./taint):** Marks a specific resource instance as degraded to force recreation on the next apply.
- **[`testform untaint`](./untaint):** Removes the tainted mark from a resource instance in state.
- **[`testform force-unlock`](./force-unlock):** Manually releases a stuck state lock left behind by an aborted pipeline.
