Pipeline Guard

Bloquea el Drift antes del Merge: Verificación estricta en PR

GitHub Actions y GitLab CI ejecutan automáticamente testform plan y testform audit en cada Pull Request.

Si un desarrollador modifica la lógica de un endpoint o servicio pero no actualiza las pruebas vinculadas, la CI frena el pipeline en seco. Cero trabajo manual de sincronización, cero reuniones de reconciliación en hojas de cálculo.

check_circle Análisis de cambio especulativo en tiempo real
check_circle Comentario automatizado con diff de pruebas en el PR
check_circle Sello criptográfico adjunto a los artefactos del commit
terminal .github/workflows/ci.yml
GitHub Actions 
name: "Testform State & Drift Validation"
on:
  pull_request:
    branches: [ main, release/* ]

jobs:
  testform-drift-guard:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository Code
        uses: actions/checkout@v4

      - name: Setup Node.js Runtime
        uses: actions/setup-node@v4
        with:
          node-version: '20.x'

      - name: Install Testform Engine CLI
        run: npm i -g @fromeroc9/testform@beta

      - name: Initialize Remote State Bucket
        run: testform init --backend=s3 --bucket=${{ secrets.TF_STATE_BUCKET }}

      - name: Execute Speculative Drift Plan
        run: |
          testform plan --drift-guard --detailed-exitcode \
            --out=pr-spec-plan.tfplan

      - name: Seal Immutable Execution Audit
        if: always()
        run: testform audit --verify --report-pr=${{ github.event.number }}
